# FossilFinder

FossilFinder is a searchable digital paleontology archive that allows users to explore prehistoric animals by name, classification, diet, and geological period. Each specimen is presented through a museum-inspired interface containing information such as scientific classification, estimated size, fossil range, notable traits, and historical facts.

The application was built with React and TypeScript, with Supabase providing a PostgreSQL-backed database for structured specimen data. FossilFinder uses asynchronous database queries and dynamic React rendering to generate reusable specimen cards from search results, allowing a single search to return individual dinosaurs or broader groups such as theropods, herbivores, and Cretaceous species. The interface was designed with responsive CSS and an archival natural-history aesthetic. As always, updates will be made over time.
